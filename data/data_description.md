# 数据集说明

## 数据来源
本数据集由 Python 脚本 `generate_data.py` 自动生成，为模拟数据集，非真实工业数据。

## 数据集简介
- **文件名**：`robot_data.csv`
- **样本数量**：1000 条
- **特征数量**：6 个字段

## 字段说明

| 字段名 | 单位 | 取值范围 | 说明 |
| :--- | :--- | :--- | :--- |
| 时间 | s | 1~1000 | 模拟运行时间 |
| 关节角度 | ° | -180~180 | 模拟关节转动角度 |
| 电机电流 | A | 1~20 | 模拟驱动电流 |
| 振动值 | mm/s | 0.1~10.0 | 核心特征，反映抖动程度 |
| 温度 | ℃ | 20~90 | 核心特征，反映发热程度 |
| 健康状态 | 类别 | 平稳/轻微抖动/严重抖动 | 标签 |

## 标签生成规则

| 健康状态 | 振动值条件 | 温度条件 |
| :--- | :--- | :--- |
| 平稳 | < 2.0 | < 50 |
| 轻微抖动 | 2.0~5.0 | 50~70 |
| 严重抖动 | > 5.0 | > 70 |

## 数据分布

| 健康状态 | 样本数量 |
| :--- | :--- |
| 平稳 | 约 269 |
| 轻微抖动 | 约 273 |
| 严重抖动 | 约 458 |

## 数据质量
- 无缺失值
- 无异常值
- 特征与标签逻辑一致
