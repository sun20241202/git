# 基于振动特征分析的工业机器人关节健康状态智能诊断系统

## 项目简介
本项目是一个面向工业机器人关节健康状态的智能诊断系统，通过分析振动和温度传感器数据，利用机器学习模型自动判断机器人关节的运行状态（平稳/轻微抖动/严重抖动），并提供健康寿命经验估算功能，为设备维护提供参考。

## 功能列表
- 模拟传感器数据生成（1000条样本）
- 基于随机森林的健康状态分类模型（准确率96.5%）
- RESTful API 接口（预测 + 历史记录查询）
- 可视化仪表盘（状态指示灯 + 健康度进度条 + 寿命预估）
- SQLite 数据库存储预测历史
- 自动化测试（unittest 框架，3个测试用例）
- 健康寿命经验估算（基于状态映射）

## 技术栈
- Python 3.x
- Flask（后端框架）
- scikit-learn（机器学习）
- SQLite（轻量级数据库）
- HTML + CSS + ECharts（前端可视化）

## 系统架构
用户输入振动值/温度 → 后端API → 加载模型预测状态 → 返回状态 + 经验寿命估算 → 前端展示 + 存入数据库

## 数据说明
- 数据来源：程序自动生成的模拟数据（`generate_data.py`）
- 样本数量：1000 条
- 特征：振动值、温度
- 标签：平稳 / 轻微抖动 / 严重抖动
- 预处理：标签编码 + 特征标准化（`preprocess.py`）
- 详细说明：见 `data/data_description.md`


## 运行方法
1. 生成模拟数据：python generate_data.py
2. 训练分类模型：python train_model.py
3. 启动后端服务：python app.py
4. 在浏览器中打开 frontend/index.html

## 健康寿命预估功能说明
本系统提供的“健康寿命预估”为经验估算值，基于预设的工程经验规则生成，主要用于功能演示和概念验证：

| 健康状态 | 健康度 | 预估剩余寿命（经验参考值） |
| :--- | :--- | :--- |
| 平稳 | 85% | 约 800+ 小时 |
| 轻微抖动 | 60% | 约 300 小时 |
| 严重抖动 | 30% | 建议立即检修 |

⚠️ 注意：该估算值仅用于展示系统功能（经验粗略估算，假设寿命为1000小时所估算的结果），不代表真实设备的实际剩余寿命。在真实工业场景中，寿命预测需结合更全面的传感器数据、设备型号、历史故障记录及专业模型进行标定。
